# Unduhan SIDIGIT

Asisten digital guru **SMP Negeri 23 Dumai**: SIDIGIT-OMR (koreksi LJK), SIDIGIT-Time
(jadwal pelajaran), SIDIGIT PDF, SIDIGIT-GNP, dan aplikasi Android SIDIGIT Pindai.

Repo ini hanya berisi **berkas rilis**. Unduh versi terbaru di halaman
[Releases](https://github.com/SIDIGIT-23/sidigit-rilis/releases/latest):

| Sistem | Berkas |
|---|---|
| macOS (Apple Silicon & Intel) | `SIDIGIT-OMR-<versi>-macos-universal.dmg` |
| Windows 10/11 64-bit | `SIDIGIT-OMR-<versi>-windows-x64-setup.exe` |
| Android (SIDIGIT Pindai) | `sidigit-pindai-arm64-v8a-release.apk` |

Cek keaslian berkas dengan `SHA256SUMS.txt`. Berkas `update.json` dibaca aplikasi untuk
memberi tahu versi baru; isinya ditandatangani (ed25519), dan aplikasi menolak berkas
yang tanda tangannya tidak cocok.

Pertanyaan: [E-Office SIDIGIT-23](https://e-officesmpn23dmi.com) · [Web SMPN 23 Dumai](https://www.smpn23dumai.com)
